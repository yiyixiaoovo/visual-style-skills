# 01 · 视觉语法：14 个母题

「舟味」不是一种色调，是**一组可以被数出来的排版动作**。下面 14 个母题，任意 4–6 个组合就成立；
超过 7 个会互相打架（尤其 M06/M07/M11 三个纹理类不能同时出现）。

组合之前先记住这套系统的底座是：**印刷品隐喻**（档案、工业、军事文件）+ **单色纪律** + **双层信息结构**
（视觉层用西文巨字，文本层用中文与元信息，两层永不同字号）。

---

## M01 · 出血巨字
- **做什么**：让标题大到必须被画布裁掉，制造"这只是一份文件的局部"的错觉。
- **怎么做**：字号 ≥ 版面宽度的 1/3；`line-height: .8`；`letter-spacing: -.06em`；至少一边越过版心（`margin-right: -56px`）。
- **用在哪**：竖版海报、章节页、封面、活动 KV。
- **别怎么用**：16:9 幻灯片里慎用（高度不够，会挤掉数据栏）；正文页不要用。

## M02 · 实心 / 描边并置
- **做什么**：同一标题的两行，一行填实、一行只留 1.5px 轮廓，制造印刷"套色"的错觉。
- **怎么做**：`.ak-outline { color: transparent; -webkit-text-stroke: 1.5px var(--ak-paper); }`
- **用在哪**：所有出现两行英文标题的地方。
- **别怎么用**：描边字不能放在复杂背景上（网点会把轮廓吃掉）；描边不要超过 2px。

## M03 · 元信息标签层
- **做什么**：把 REF / CLASSIFIED / CLEARANCE 这类假信息排成等宽、全大写、字距 +0.18em 的小字层。
- **怎么做**：`.ak-label`；字号 10–11px；字距 0.18–0.3em；颜色为次级纸白。
- **用在哪**：页眉、页脚、图注、数据栏的键名。
- **别怎么用**：这一层一旦用中文字体或加粗，立刻掉档；不要超过 3 行以上连续出现。

## M04 · 竖排轨道
- **做什么**：页面最左侧一条 16–24px 的竖排英文，把版心"框"住，产生装订边。
- **怎么做**：`writing-mode: vertical-rl; letter-spacing: .38em;` 配一条 1px 竖线延伸到底。
- **用在哪**：海报、长图、封面。
- **别怎么用**：竖排里不要塞长句（>12 字符会读不出来）；不要两侧都放。

## M05 · 裁切标记与刻度
- **做什么**：四角裁切十字 + 边上的刻度尺，暗示"这是一张待付印的版"。
- **怎么做**：`.ak-crop`（四角十字）、`.ak-ticks`（12px 周期刻度）、`.ak-crosshair`。
- **用在哪**：所有静态版面；幻灯片只用刻度不用裁切。
- **别怎么用**：不要加真实的印刷色条（CMYK 色块）除非真在讲印刷。

## M06 · 半调网点
- **做什么**：45° 网屏的点阵，让纯色块看起来是"印上去的"而不是"填上去的"。
- **怎么做**：`radial-gradient(circle, currentColor 34%, transparent 36%)` + `background-size: 5–6px`，容器 `rotate(-45deg)`，不透明度 0.1–0.15。
- **用在哪**：图版底、巨字背后的阴影、渐隐过渡。
- **别怎么用**：点径 < 4px 在 1× 截图里会糊成灰；不要整页铺满。

## M07 · 扫描线
- **做什么**：1px 横线、3px 周期，叠在影像上，模拟终端 / 显像管。
- **怎么做**：`.ak-scan`，不透明度 0.15–0.2；**只在图版上**，不要盖文字。
- **用在哪**：人物图版、终端面板。
- **别怎么用**：正文上铺扫描线会显著降低可读性；不要与网点同密度叠加。

## M08 · 双色调影像
- **做什么**：把彩色照片压成"单色 + 一个色相"的印刷图。
- **怎么做**：`filter: grayscale(1) contrast(1.35)` + 叠色层 `mix-blend-mode: color`。
- **用在哪**：有真实素材时的人物 / 场景。
- **别怎么用**：不要既双色调又高饱和；肤色不要压成橙红（会脏）。

## M09 · 几何剪影（无素材时的替身）
- **做什么**：用圆 + 肩线拼一个"戴面罩的人"，替代不存在的插画。
- **怎么做**：头部为圆，肩为一条宽贝塞尔曲线；面罩用 `clip-path: circle()` 裁一条深色横槽，槽底加 2px 强调线。
- **用在哪**：没有版权素材的演示稿、placeholder。
- **别怎么用**：别画细节（五官、服装褶皱）；它是"符号"，不是"插画"。

## M10 · 斜切 / 缺角
- **做什么**：把矩形的角切掉，制造"被机器裁过"的硬边。
- **怎么做**：`clip-path: polygon(...)` 切掉对角两角；或 `.ak-notch` 画四角折线。
- **用在哪**：按钮、标签块、图版框。
- **别怎么用**：切角尺寸要统一（12/18/24 三档），混用会显得手抖。

## M11 · 危险斜纹
- **做什么**：45° 窄条斜纹，只出现在边缘或角上，面积 < 2%。
- **怎么做**：`repeating-linear-gradient(45deg, var(--ak-signal) 0 6px, transparent 6px 12px)`。
- **用在哪**：一个角、一条边、一个 96×96 方块。
- **别怎么用**：绝不整块铺满；绝不与橙色大字同页大面积共存。

## M12 · 条码 / 编号 / 印章
- **做什么**：底部条码 + `AK·ED·07·1225·B` 这类伪编码 + 一枚旋转 −6° 的描边印章。
- **怎么做**：两道不同步频的 `repeating-linear-gradient` 叠成条码；印章用 2px 描边 + 字距 0.3em。
- **用在哪**：页脚；每页最多 1 个条码、1 枚印章。
- **别怎么用**：不要做可扫描的真条码（会被当真）；印章文字不超过 12 字符。

## M13 · 静区 + 巨型描边数字
- **做什么**：在中部留出 ≥ 35% 的空白，只放一个 300px 的描边编号作锚。
- **怎么做**：`color: transparent; -webkit-text-stroke: 1px var(--ak-line-strong); opacity: .55`。
- **用在哪**：海报中段、章节页。
- **别怎么用**：静区里不要再塞第二个元素；描边数字不要实心。

## M14 · 层叠与遮挡
- **做什么**：巨字压在人物图版下面或上面，形成"印刷叠印"的前后关系。
- **怎么做**：给标题 `z-index` 高于图版，让描边字穿过人物；或反之，让图版压掉半行字。
- **用在哪**：所有存在"巨字 + 图版"的版面。
- **别怎么用**：遮挡不要发生在信息栏（会读错数据）；实心字被图版遮住会变成错字。
