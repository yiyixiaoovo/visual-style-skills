# 00 · 证据分级（Evidence）

这套系统里每一个数值都标了它是**怎么来的**。用途只有一个：**别把"我猜的"当成"官方的"卖出去**。

## 三级置信度

| 级别 | 定义 | 能不能进令牌 | 能不能写成硬规则 |
|---|---|---|---|
| **A · 实测** | 从官方站点/官方 CSS 里读到的原始声明 | ✅ 可以 | ✅ 可以 |
| **B · 推断** | 从公开美术分析、多张官方物料反复出现中归纳 | ⚠️ 可以，但必须在注释里标注 B | ❌ 只能做"建议" |
| **C · 装饰** | 为了效果自己选的，官方并未如此 | ✅ 可以 | ❌ 不可，且必须可一键关闭 |

> 规则：**B 级不得单独构成硬规则；C 级不得出现在 `ak.css` 的 `:root` 里，只能出现在模板私有样式。**

## 已知的社区冲突（别被带偏）

| 来源 | 主张 | 与实测的关系 |
|---|---|---|
| `ganmayou2333/Arknights-Visual-Design-Skills` | 基底 `#1A1C20`、主色 `#3F72AF`、强调 `#56B6C9` | 与官方 CSS **不一致**：官方基底是纯黑、主色是青 `#18d1ff`。那套是"再创作"配色，可以直接用，但**不能标称"官方色"** |
| 同上 | 45° 切角（左上＋右下） | 实测官方几乎只有 0/4px 圆角，切角属 **B/C** 级演绎 |
| `Rad-Weed/rhine-lab-motion` | 纸白 `#e7e5e1` + 警告橙 `#ff7b00` | 这是**莱茵生命阵营**的演绎，不是全游戏主色；本包把它收进 `data-faction="rhine"` 正合适 |
| `terra-faction-ui` | 十二阵营各有独立骨架与控件语法 | 方法论值得借（见下），配色同样是演绎 |

**结论**：做"全局视觉"用 A 级；做"某阵营"可以整套用 B/C 级，但必须在成稿里说明这是二创。

## 借用来的三条方法论

本包这几处不是原创，注明出处：

1. **证据置信度分级 + 相邻方案必须差异化** ← `Brandon030722/terra-faction-ui`
   （它的规则是"相邻阵营至少在主轴、导航、决策、重叠、仪器关系中改变三项"，本包改写为 `03-layouts.md` 的配方差异化规则）
2. **生成模式 / 评估模式双入口 + 禁忌一票否决** ← `ganmayou2333/Arknights-Visual-Design-Skills`
   （本包落到 `05-quality-gates.md` §0）
3. **跨 harness 兼容层（AGENTS.md + 自检脚本）** ← `Rad-Weed/rhine-lab-motion`
   （本包落到根目录 `AGENTS.md` 与 `scripts/validate-package.mjs`）
