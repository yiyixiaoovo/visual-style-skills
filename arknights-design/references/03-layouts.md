# 03 · 版式配方 R1–R8

**规则：先选配方，再填内容。** 不允许"边排边想"——那一定滑向居中堆叠的默认样式。
每个配方都给了线框、尺寸与必用母题（编号见 `01-visual-grammar.md`）。

坐标一律以 1200×1600 竖版为基准，换尺寸时按比例缩放，页边保持 56px。

```
┌──────────────────────────────────┐
│ 源石浓度监测 / CONCENTRATION      │ 标题 32–44px
│ ──────────────────────────────── │

│ 03  区域 C        0.91 ppm  ▁▅▇█ │ 异常行用强调色
```

- 图表**不用现成图表库**：`div` + 高度百分比 + 1px 基线即可，视觉上更统一。
- 数值全部 `.ak-num`（等宽表格数字），小数位对齐。
- **必用**：M03 M05 M06 M10。

```
┌────────────────────────────────┐
│                                │
│                                │

│                                │
│                                │
│         ── 02                  │ 小标签

│         OBSERVATION LOG        │ 描边英文
│                                │

└────────────────────────────────┘
```

- 整页只有一个锚点 + 一条线，留白 ≥ 60%。
- 编号用**实心**，章节标题用**描边**——和 R1 的实心/描边关系反过来用。

## R6 · 双栏跨页（对比 / Before-After）

```
┌───────────────┬────────────────┐
│ A             │ B              │
│ ████          │ ░░░░           │
│ 现状 / CURRENT│ 目标 / TARGET   │
│ · 数据 1      │ · 数据 1        │
│ · 数据 2      │ · 数据 2        │
└───────────────┴────────────────┘
```

- 中线用 1px `--ak-line`，**不要用色块分割**（色块一多就变成 PPT 模板）。
- 两侧同构：字段名、行数、字号完全一致，只有内容与强调色不同。

---

## R7 · 长图（公众号 / 小红书竖长图）

- 分段复用 R1 / R4 / R5，每段高度 = 1200 的整数倍，段间用 56px 页边 + 一条 `--ak-line` 过渡。
- **每 2 屏必须出现一次"密"**，否则整张图读起来像流水账。
- 顶部固定一条进度刻度（`.ak-ticks` + 当前段高亮）。

---

## R8 · 网页头图（1920×1080，可滚动）

- R1 的横向改写：巨字左，图版右，底部压一条 120px 数据条并`position: sticky`。
- 首屏不放长文；滚动后才出现 `.ak-body`。
- 动效只允许「显影」（进入视口时 `clip-path` 揭示一次），且 `prefers-reduced-motion` 必须降级为直接显示。

## 配方速选表

| 用户要什么 | 选 | 尺寸 |
|---|---|---|
| 活动海报 / 主视觉 | R1 | poster 1200×1600 |
| PPT / 汇报 | R2 | slide 1600×900 |
| 角色 / 干员卡 | R3 | card 750×1000 |
| 数据长图 / 信息图 | R4 + R7 | 1200 宽 |
| 大图册分节 | R5 | square 1080×1080 |
| 对比页 | R6 | slide |
| 社媒方图 | R5 或 R3 | square 1080×1080 |

## 配方差异化规则（同一套物料里）

相邻两张版面必须在下面 5 项里**至少改 3 项**，否则只是同一张图换了文案：

| # | 轴 | R1 档案封面 | R5 章节页 |
|---|---|---|---|
| 1 | 主轴方向 | 横：左字右图 | 纵：上号下题 |
| 2 | 信息层数 | 4 层（巨字/中文/标签/数据） | 2 层（编号/标题） |
| 3 | 主语位置 | 左上 1/3 | 右上 2/3 |
| 4 | 图版占比 | 42% | 0% |
| 5 | 装饰密度 | 高（刻度/条码/印章） | 低（一条线） |

做系列物料时，把这张表填满再动手——否则一套四页会有三页长得一样。
