# 09 · 真实素材接入

本包所有模板默认是**"无素材"版式**（剪影 / 几何图版 / 剖面图）。一旦客户给了照片或插画，按这四步接，别直接往版上怼。

## 1. 先归一

| 项 | 要求 | 为什么 |
|---|---|---|
| 色彩 | sRGB / 8bit | 否则双色调会偏色 |
| 尺寸 | ≥ 版面尺寸的 **2×**（1200 宽海报 → 图 ≥ 2400px） | 2× 导出时不虚 |
| 命名 | `主体_来源_编号.jpg`，不覆盖原件 | 返工时能找回原图 |
| 透明 | 带 alpha 的 PNG 单独存，**不要压平** | 压平后再抠就废了 |

## 2. 裁切决定一切

| 版面 | 裁切比 | 主体位置 | 注意 |
|---|---|---|---|
| R1 海报 | 4:5 竖 | 上 1/3 | 下方留给数据栏 |
| R3 档案卡 | 1:1 | 居中偏上 | 头部占画面 1/2 |
| R5 章节 | 16:9 横 | 偏一侧 | 另一侧留给巨字 |
| R8 网页头图 | 16:10 | 右侧 | 左侧留给标题与 CTA |
| R7 长图 | 21:9 条 | 居中 | 只做"气氛条"，不承载信息 |

三条硬规矩：
1. **只裁一次**。反复裁切（先裁大再裁小）会糊。
2. 主体边缘留 ≥ **8%** 呼吸，不许贴边。
3. **视线要指向文字区**，不要指出版面——人看哪儿，读者就看哪儿。

## 3. 双色调（`.ak-duotone` 已经写好）

三步：`grayscale(1)` → `contrast(1.35)` → 叠色 `mix-blend-mode: color`（不透明度 .45–.6）。

| 素材 | 建议 | 禁止 |
|---|---|---|
| 人像 | 冷灰底 + 单色，肤色保留明度层次 | 压成橙红（显脏） |
| 场景 | 压成冷灰 + 一个强调色 | 保留原色（破坏单色纪律） |
| 产品/道具 | 高对比黑白，局部保留一个色相 | 既双色调又高饱和 |

## 4. 网点、抠像、剪影

- **网点**：`.ak-halftone` 或 `mask-image: radial-gradient(...)`；网点面积 **≤ 15%**，只压在图版上，不许盖文字。
- **抠像**：优先 `mask-image`（边缘更自然），其次 `clip-path`；羽化 2–4px。
- **剪影**：`filter: brightness(0)` 做纯黑剪影，再按需反白；用于"不想露脸"或占位。

## 5. 四条禁令

1. **原图直出**（未做任何处理就放上去）
2. **彩色照片**直接进单色版面
3. 使用**官方立绘 / LOGO / UI 截图**（版权 + 一眼假）
4. 用 `object-fit: fill` 拉伸变形（永远 `cover`）

## 6. 版权

- 素材必须自有或已获授权；保留授权凭证。
- 官方素材只能做**风格参考**（量色、量比例），不能进成稿。
- 客户给的素材，默认只在当前项目内使用。

## 7. 接入检查表

- [ ] 尺寸 ≥ 2×，色彩 sRGB
- [ ] 只裁切过一次，主体留白 ≥ 8%
- [ ] 主体视线朝向文字区
- [ ] 已做双色调或网点（无原图直出）
- [ ] 网点/纹理面积 ≤ 15%，未覆盖文字
- [ ] 素材授权可追溯
