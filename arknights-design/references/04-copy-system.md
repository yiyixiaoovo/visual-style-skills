# 04 · 文案与双语系统

**这是最容易被跳过、却最决定"像不像"的一层。**
舟味的信息结构不是"中文标题 + 英文翻译"，而是**两层并列的信息**：
英文层负责骨架与节奏（可以无意义、可以缩写），中文层负责锚点（具体、短、可读）。
两者**不是互译关系**。

---

## 1. 双语结构

| 层 | 角色 | 字体 | 允许内容 |
|---|---|---|---|
| L1 巨字 | 视觉骨架 | 显示字体、全大写、压缩 | 1–2 个英文词，可无意义（SILENT / PROTOCOL / ORIGINIUM） |
| L2 中文 | 信息锚点 | 中文黑体、600 字重 | 4–6 字标题；≤ 12 字副标 |
| L3 标签 | 伪元数据 | 等宽、全大写、字距 .18em | 见下方词库 |
| L4 数据 | 具体事实 | 等宽数字 | 编号、坐标、时间、百分比 |

**反例**：`英文 SILENT PROTOCOL` + `中文 "静默协议"` 是**同一句话的两遍**——信息量为零。
**正例**：`英文 SILENT PROTOCOL`（行动代号）+ `中文「静默协议」`（这是给中文读者的锚）+ 副标 `一次没有回声的撤离行动`（新增信息）。

---

## 2. 英文标签词库（直接取用）

### 页眉 / 页脚
`RHODES ISLAND` `ARCHIVE TERMINAL` `ISSUED BY` `REF.` `DOC. NO.` `PAGE` `OF` `ANNEX` `ADDENDUM`
`CLEARANCE` `CLASSIFIED` `RESTRICTED` `DECLASSIFIED` `SEALED` `DESTROY AFTER READING`

### 版面
`SUBJECT` `OPERATOR` `SECTOR` `ZONE` `STATUS` `ACTIVE` `STANDBY` `OFFLINE` `TERMINATED`
`ORIGIN` `CLASS` `RARITY` `AFFILIATION` `DETACHMENT` `SQUAD` `UNIT` `SIGNAL` `LINK`
`OBSERVATION` `SAMPLING` `CONCENTRATION` `EXPOSURE` `THRESHOLD` `PROTOCOL` `OPERATION`

### 时间 / 位置
`1225.10.04`（点分日期，不用 `/` 与 `-`）`04:00–04:40` `S-07` `GRID 41.7N` `SECTOR 12`

### 语气
- 全大写；句末不加句号；不用感叹号、问号。
- 缩写优先：`DEPT.` `NO.` `REF.` `FIG.` `CAP.` `EST.`
- 允许出现"系统自己说的话"：`LINK ESTABLISHED` `SCAN 1:1` `NO AUDIO RECOVERED` `SIGNAL LOST`

## 3. 中文词库（档案语汇）

| 类别 | 可用词 |
|---|---|
| 文件 | 档案 · 卷宗 · 附录 · 附件 · 记录 · 备案 · 封存 · 解封 |
| 行动 | 协议 · 行动 · 撤离 · 回收 · 观测 · 封锁 · 静默 · 清场 |
| 地点 | 矿区 · 废墟 · 走廊 · 甲板 · 隔离区 · 中转站 · 观测点 |
| 状态 | 异常 · 超标 · 失联 · 稳定 · 待命 · 已归档 |
| 名词化 | 「静默」「回收」「观测」可直接当标题（去动词化是档案语体的核心） |

**中文标题写法**
- 4–6 字最佳（`静默协议` `观测记录` `第 07 号档案`）；
- 不加"的"、不用形容词堆叠、不用疑问句；
- 副标 ≤ 12 字，写**具体事实**（`一次没有回声的撤离行动`），不写评价（`一场震撼人心的旅程`）。

## 4. 编号体系

```
AK · ED · 07 · 1225 · B
└┬┘ └┬┘ └┬┘  └─┬─┘  └┬┘
 │   │   │     │     └ 权限等级 A / B / C
 │   │   │     └────── 日期 MMDD 或 YYMM
 │   │   └──────────── 序号，补零两位
 │   └──────────────── 分类两字母：ED 版式 / OP 行动 / RC 记录 / AN 附录
 └──────────────────── 项目两字母
```

- 编号**必须出现在页脚**，且与页眉的 REF 不同（页眉是文档号，页脚是文件号）。
- 序号在同一套物料里连续（07 → 08 → 09），体现"这是一系列"。
- 不要在编号里放真实日期、真实人名、真实机构。

## 5. 禁用词（写了就返工）

`极致` `赋能` `打造` `一站式` `沉浸式` `未来感` `科技感` `赛博` `颠覆` `重塑` `解锁`
`✨` 等 emoji `！` `？` `~` `「最好的」` 任何营销口号、任何第二人称劝说（`你值得`）

## 6. 字数硬上限

| 元素 | 上限 |
|---|---|
| 英文巨字（每词） | 9 字符 |
| 中文主标题 | 6 字 |
| 中文副标 | 12 字 |
| 标签行 | 8 字符 |
| 正文段落 | 40 字（超过就拆成条目） |

## 7. 一页的信息预算

- 巨字 1 组（1–2 词）
- 中文锚点 1 个
- 标签 ≤ 10 条
- 数据字段 ≤ 4 个
- 图注 ≤ 2 条

超预算就把内容拆到下一页——**宁可多一页，不要一页塞满**。
