# 05 · 质检与打分

出稿前必须过两道关：**机器检查**（`scripts/verify.mjs`）+ **人眼三秒测试**（截图看）。
机器能查的是"纪律"，人眼才能判断"版面对不对"。

---

## 0. 一票否决（先查这个，命中即 0 分）

以下任意一条命中，**不看分数，直接返工**：

| # | 否决项 | 为什么致命 |
|---|---|---|
| V1 | 出现官方 LOGO / 立绘 / UI 截图 / 受保护字体 | 版权风险 + 一眼假 |
| V2 | 圆角 > 4px，或出现胶囊形 | 立刻变成通用 SaaS |
| V3 | 有彩色 > 2（印章红另计且 ≤ 1 处） | 单色纪律破了 |
| V4 | 投影 / 彩色发光 / 装饰性渐变 | 廉价赛博朋克 |
| V5 | 中文最大字号越级（有巨字时 > 1/3） | 中西混排塌方 |
| V6 | 无标签层 / 无编号 | 那不是档案，只是排版 |
| V7 | 成稿里出现未量化表述（"约""适中""科技感"） | 说明根本没做决策 |

机器侧覆盖：V2–V7 由 `scripts/verify.mjs` 检查（任一 FAIL 等同命中否决项）；**V1 只能人眼查**。
## 1. 三秒测试（人眼，必做）

把最终 PNG 缩到 400px 宽，**只看 3 秒**，然后回答：

1. 你知道这张图在说什么吗？（锚点是否成立）
2. 你的视线第一落点在哪？是不是你设计的那一个？
3. 有没有哪个元素在"抢戏"（颜色太亮 / 字号不该大）？
4. 缩小后还读得出来吗？（舟味的一个硬指标是缩略图也可辨识）

四项有一项答不上来，回版式，不要靠加装饰去救。

---

## 2. 机器检查：10 项

| # | 检查项 | 通过标准 | 失败后的修法 |
|---|---|---|---|
| 1 | 圆角 | 全文件无 `border-radius` 或值为 `0` | 删掉；要软边用切角 |
| 2 | 有彩色数 | 不同色相 ≤ 2（不含印章红） | 把多的那个改成灰阶明度 |
| 3 | 色板外颜色 | 只允许 `02-tokens.md` 里的值 | 用 token，不要随手 `#333` |
| 4 | 字体 | 只允许 4 个角色族 | 见 `assets/fonts.md` |
| 5 | 字距 | 显示级有 `-.0Xem`；标签层有 `+.18em` 以上 | 补 `letter-spacing` |
| 6 | 阴影/发光 | 无 `box-shadow`、无 `text-shadow: 0 0 Npx <彩色>` | 删；层级用线与遮罩 |
| 7 | 渐变 | 只允许网点、影像渐隐、遮罩 | 删除装饰性 `linear-gradient` |
| 8 | 禁用词 | 无 `极致/赋能/打造/未来感/科技感/emoji` | 换 `04-copy-system.md` 词库 |
| 9 | 结构件 | 至少有：标签层、分割线、页脚元信息 | 补页眉页脚 |
| 10 | 中文字号 | 有巨字（≥150px）时 ≤ 巨字 1/3；无巨字时 ≤ 72px 且 ≤ 西文 0.7× | 缩小中文，或加大巨字 |

跑法：

```bash
node scripts/verify.mjs templates/poster-3x4.html
```

输出每项 PASS/FAIL + 一句修法；有 FAIL 时不建议交付。

## 3. 评分表（人眼，20 分制）

每项 0 / 1 / 2 分。**≥ 16 分**才叫"像"；12–15 分是"有元素但没气质"；< 12 分基本是通用设计贴了点装饰。

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| **锚点** | 没有主次，处处一样重 | 有主标题但被别的元素抢 | 一眼一个锚，其余全部退后 |
| **单色纪律** | 彩色 ≥ 4 种或有大面积彩块 | 2 种彩色但面积失衡 | 1 主 1 状态，面积 < 5% |
| **层级** | 只有大中小三级字号 | 有标签层但不统一 | 巨字/中文/标签/数据 四层分明 |
| **留白** | 填满，无静区 | 有空白但不集中 | 有一块 ≥ 35% 的完整静区 |
| **图版** | 无图或原图直出 | 有处理但不统一 | 双色调/剪影/网点，与版面对齐 |
| **文字** | 中英同字号并排 | 双语但不分工 | 英骨架 + 中锚点 + 假元数据，三层各司其职 |
| **细节** | 圆角/阴影/描边混乱 | 细节对但不密 | 刻度、条码、编号、印章成套 |
| **缩略图** | 缩到 400px 就散架 | 能看出是海报 | 缩略图反而更好看（对比被放大） |

## 4. 反模式图鉴（见到就删）

| 反模式 | 为什么致命 | 换成 |
|---|---|---|
| 紫/蓝渐变背景 | 通用 AI 模板签名 | 纯黑 + 网点 |
| 圆角卡片 + 柔和投影 | SaaS 落地页 | 直角 + 1px 线 + 切角 |
| 彩色线性图标 | 打断单色纪律 | 单色线稿 SVG，`filter: brightness(0) invert(1)` |
| emoji 当图标 | 语域完全错 | 几何符号或不用 |
| 居中堆叠一切 | 没有版心概念 | 左对齐 + 右侧图版，非对称 7:5 |
| 中英同字号 | 双语不分工 | 英大中文小，或中文独占一行 |
| 发光/霓虹描边 | 赛博朋克，不是舟 | 1px 实边 |
| "科技感/未来感"口号 | 词穷 | `04` 词库里的档案语汇 |
| 大面积橙黄斜纹 | 工地警示带 | 只在一个角上出现 |
| 每页都放条码印章 | 装饰通货膨胀 | 摊到系列里，别每页都放 |
