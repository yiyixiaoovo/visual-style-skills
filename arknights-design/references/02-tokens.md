# 02 · 设计令牌

所有值都在 `assets/ak.css` 的 `:root` 里，**改这里，不要改模板里的硬编码**。

## 1. 色彩

### 1.1 中性（永远占画面 90% 以上面积）

| Token | 值 | 用途 |
|---|---|---|
| `--ak-void` | `#08090a` | 暗色模式全页底 |
| `--ak-plate` | `#111316` | 图版 / 卡片底 |
| `--ak-plate-2` | `#191c20` | 二级面（数据栏底、浮层） |
| `--ak-paper` | `#e8e6e1` | 正文与巨字（不是纯白） |
| `--ak-paper-2` | `#c9c5bb` | 次级文字、标签 |
| `--ak-ink` | `#0b0c0e` | 纸模式下的墨色 |
| `--ak-line` | `rgba(232,230,225,.16)` | 细分割线 |
| `--ak-line-strong` | `rgba(232,230,225,.38)` | 刻度、裁切标记、描边数字 |

### 1.2 有彩色（配额制：整页 ≤ 2 + 1 处印章）

| Token | 值 | 语义（不要换用） |
|---|---|---|
| `--ak-signal` | `#ff7b00` | **主强调**：当前、运行、主标题的强调线 |
| `--ak-cyan` | `#18d1ff` | **状态**：在线、链路、系统 |
| `--ak-vermillion` | `#b0243b` | 印章 / 封条专用，面积 < 1% |
| `--ak-lime` | `#b9e432` | 确认态，只做 6px 的点，不作面 |

**用法纪律**
- 一张图里，`--ak-signal` 出现的次数可以多（3–5 处），但面积必须小（线段、方块、单行字）。
- 不允许"橙色块 + 青色块"平分画面——那不是强调，是配色。
- 不要引入第五个色相。需要第三种语义时，改用**明度**区分（纸白 / 灰 / 深灰）。

### 1.3 两套模式

| 模式 | 触发 | 感觉 |
|---|---|---|
| 暗色（默认） | `<body data-mode="dark">` | 终端、档案库、夜间简报 |
| 纸色 | `<body data-mode="paper">` | 印刷品、公告、年鉴 |

两套模式共用同一结构，只换纸与墨；切换时不需要改任何布局。

---

### 1.4 阵营槽（换了阵营，结构一行不改）

`[data-faction]` 只做一件事：换配色槽。其中 `laterano` 会连**中性色的色温**一起换（冷调蓝灰），
其余阵营只换强调色。

| 阵营 | `--ak-accent` | `--ak-status` | 中性色 |
|---|---|---|---|
| `rhodes`（默认） | `#18d1ff` 青 | `#8fc31f` 绿 | 标准暖灰 |
| `rhine` | `#ff7b00` 橙 | `#18d1ff` | 标准暖灰 |
| `hyper` | `#f3ff00` 荧光黄 | `#18d1ff` | 标准暖灰 |
| `terran` | `#b0243b` 朱红 | `#18d1ff` | 标准暖灰 |
| `laterano` | `#9ad9e8` 圣光青 | `#e8e2cf` 骨白 | **冷调**：`#0a0d11` / `#121820` / `#e6e9ec` |

冷调是"庆典 / 圣城 / 仪式"的语域；暖灰是"档案 / 军事 / 终端"的语域。**不要混用。**
## 2. 字体

| 角色 | 栈 | 说明 |
|---|---|---|
| 显示（英文巨字） | `Bahnschrift` → Oswald → Archivo Narrow → Arial Narrow | Bahnschrift 是 Windows 自带的 DIN 变体，压缩、机械，最接近舟味显示字 |
| UI | `Bahnschrift` → Segoe UI | 标题以外的英文 |
| 中文 | `Microsoft YaHei` → Noto Sans SC → PingFang SC | 必须显式声明，不要继承西文字体 |
| 等宽 | `Cascadia Mono` → Consolas → JetBrains Mono | 标签层、编号、条码 |

**规则**
1. 允许联网时，可加载 `Oswald` + `Noto Sans SC` 作增强；但**离线必须仍然成立**——这是硬要求。
2. 中文永不使用显示字体（压缩西文没有汉字字形，回退会变形）。
3. 一页最多两套字重：700（显示）+ 400/500（正文）。不要用 300 细体做正文。

## 3. 字阶

| Token | 值 | 字距 | 行高 | 场景 |
|---|---|---|---|---|
| `--ak-fs-mega` | 200px（模板内覆写到 208） | −0.055em | .80 | 出血巨字 |
| `--ak-fs-display` | 112px | −0.05em | .82 | 章节字 |
| `--ak-fs-h1` | 64px | −0.035em | .90 | 中文主标题的同级参考 |
| `--ak-fs-h2` | 44px | −0.025em | .95 | 小标题 |
| `--ak-fs-h3` | 32px | −0.015em | 1.00 | 图表标题 |
| `--ak-fs-lead` | 19px | −0.01em | 1.50 | 导语 |
| `--ak-fs-body` | 15px | 0 | 1.65 | 正文 |
| `--ak-fs-note` | 13px | +0.02em | 1.55 | 注释 |
| `--ak-fs-meta` | 11px | +0.18em | 1.40 | 标签层 |

**中文覆盖**：`.ak-zh` 把字重降到 600、字距拉到 +0.04em；`.ak-zh--wide` 到 +0.16em（用于 4–6 字的短标题）。

## 4. 间距

8px 基线，只用这几档，不要出现 17px、30px 这类随手值：

```
4 · 8 · 16 · 24 · 32 · 48 · 64 · 96 · 128 · 160 · 200 · 256
```

版心 `1180`，页边 `56`，栏距 `20`，12 栏。

---

## 5. 动效

| Token | 值 |
|---|---|
| `--ak-dur-fast` | .2s |
| `--ak-dur` | .35s |
| `--ak-dur-slow` | .6s |
| `--ak-ease` | `cubic-bezier(.2,.7,.2,1)` |

**只允许三种动作**
1. **显影**：不透明度 0→1，配合 `clip-path` 从上往下揭开。
2. **打字**：`width` 0→100% + `border-right` 游标，或逐字 `opacity`。
3. **绘制**：`stroke-dashoffset` 从全值到 0。

禁止：`bounce`、`elastic`、`transition: all`、悬停放大 1.05、视差滚动。

## 6. 尺寸

| 类名 | 尺寸 | 典型用途 |
|---|---|---|
| `.ak-page--poster` | 1200 × 1600 | 竖版海报、活动 KV |
| `.ak-page--slide` | 1600 × 900 | 幻灯片、网页头图 |
| `.ak-page--card` | 750 × 1000 | 档案卡、商品卡 |
| `.ak-page--square` | 1080 × 1080 | 社交方图 |
| `.ak-page--a4` | 794 × 1123 | A4 打印（96dpi） |

导出倍率：交付用 2×（`--force-device-scale-factor=2`），预览用 1×。

---

## 7. 层的顺序（z-index 约定）

```
90  噪点覆层（.ak-page::after，只读纹理）
95  裁切标记（.ak-crop）
80  网格自查（.ak-grid-overlay，默认关闭）
10–70 内容层
1–3  背景图版 / 描边数字
```

模板里禁止出现 1000、9999 这类值。
