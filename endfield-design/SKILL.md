# 终末地（Endfield）视觉语域

**这是与「舟味档案」平行的第二套系统，不是它的变体。**两套的底层纪律正好相反。

| | 明日方舟（`arknights-design`） | 终末地（本技能） |
|---|---|---|
| 色 | 单主色 + 单状态，≤2 有彩 | **三色并行**，各有职责 |
| 形 | 圆角恒 0，斜切 45° | **42/54px 胶囊** + 50% 圆 |
| 光 | 零投影、禁发光 | **允许荧光晕**，每页 ≤2 处 |
| 字 | 压缩工业体（Oswald 系） | Gilroy / 宽体 + 超紧字距 |
| 节奏 | .3s / .6s，沉稳 | **.2s**，快一档 |
| 气质 | 档案、军事、克制 | 工业、霓虹、产品页 |

## 五条硬规则

1. **三色不许串岗**：黄=主操作、品红=状态、薄荷=确认。换语义不换色。
2. **圆角是语言**：主容器 42/54px，微型件才用 4/8px；**不要方角**（那是方舟）。
3. **发光只给荧光色**：`blur ≤ 60px`、每页 ≤ 2 处；中性色永不发光。
4. **大标题必须紧字距**（-.04em 起），且至少一行用描边或反白做对比。
5. **界面感优先**：宁可像个产品页，不要像张海报。胶囊按钮、状态芯片、圆形指示灯是骨架。

## 工作流

1. 选画布：`ef-page`（1600×900）/ `--tall`（1200×1600）/ `--square`（1080×1080）。
2. 铺光：1–2 个 `.ef-glow`，一黄一品红，压在角上。
3. 放碎片：2–4 个 `.ef-tri`，三色各至多一个。
4. 构骨架：导航胶囊 → 主标题（实心 + 描边两行）→ CTA 胶囊 → 描述 → 状态芯片组。
5. 右侧放面板：`.ef-panel`（54px 圆角）+ 柱状条 + 字段行。
6. 自查：三色是否各司其职？圆角是否 ≥42px？发光是否 ≤2 处？

## 分界线

- 一张图里出现**同时**「胶囊 + 荧光 + 三色」→ 终末地。
- 出现「档案编号 + 裁切标记 + 单色 + 直角」→ 方舟。
- **不要混**：把终末地的霓虹放进方舟的档案页，等于两本书拼在一起。
- 同人向方法，非官方规范；不复制 LOGO、立绘、官方 UI 像素；ProtestStrike / Gilroy 为商业字体，不做分发。
